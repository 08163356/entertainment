# 台球记分系统 - 需求与实现文档

## 项目背景

这是一个娱乐工具集项目，首期开发**台球记分系统**，用于和家人朋友打台球时实时记录比分、统计战绩。

- **GitHub**: https://github.com/08163356/entertainment.git
- **访问地址**: https://ablog.axingit.top/entertainment

---

## 功能需求

### 1. 核心记分功能

| 需求 | 说明 |
|------|------|
| 局分记录 | 记录每局胜负，显示当前比分（如 5:3） |
| 球数记录 | 每局记录赢球数（如对方剩3球，则赢3球） |
| 金额计算 | 按球数差 × 单价（默认5元/球）计算结算金额 |
| 快捷输入 | 点击胜者 → 选择球数（1-7快捷按钮或自定义） |
| 撤销操作 | 可撤销上一局记录 |

### 2. 房间系统

| 需求 | 说明 |
|------|------|
| 创建房间 | 房主创建，生成4位数房间号 |
| 加入房间 | 输入房间号 + 名字加入 |
| 实时同步 | 所有人看到的数据实时更新（WebSocket） |
| 权限控制 | 只有房主和授权者可操作记分 |
| 自动关闭 | 比赛结算后房间自动关闭 |

### 3. 角色权限

| 角色 | 能力 |
|------|------|
| 房主 👑 | 创建房间、记分操作、授权/撤销他人权限、结算 |
| 授权者 ✋ | 记分操作 |
| 观众 👁 | 实时观看、查看历史数据 |

### 4. 数据统计

| 需求 | 说明 |
|------|------|
| 历史记录 | 所有已结算比赛列表 |
| 玩家统计 | 总场次、胜负、胜率、盈亏 |
| 对手分析 | 与不同对手的胜率、盈亏 |
| 走势图 | 累计盈亏趋势折线图 |

### 5. 界面体验

| 需求 | 说明 |
|------|------|
| 主题切换 | 浅色、深色、台球绿、皇家蓝 |
| 全屏模式 | 大字体显示，适合手机横屏 |
| 响应式 | 支持手机、平板、电脑 |

### 6. 预设数据

- **预设玩家**: 阿兴、老爸、元礼
- **默认单价**: 5元/球
- **默认游戏**: 中式黑八

### 数据模型

```
Player (玩家)
├── name          # 名字（唯一）
├── is_preset     # 是否预设玩家
└── created_at

Match (比赛)
├── id            # UUID
├── room_id       # 房间号
├── game_type     # 游戏类型
├── players       # 玩家列表 JSON
├── price_per_ball
├── status        # playing / settled
├── settlement_*  # 结算结果
└── rounds[]      # 局记录

Round (单局)
├── match_id
├── round_number
├── winner
├── balls_won
└── created_at
```

### API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/rooms | 创建房间 |
| GET | /api/rooms/:id | 获取房间信息 |
| POST | /api/rooms/:id/join | 加入房间 |
| POST | /api/rooms/:id/rounds | 记录一局 |
| DELETE | /api/rooms/:id/rounds/last | 撤销上局 |
| POST | /api/rooms/:id/operators | 授权操作 |
| DELETE | /api/rooms/:id/operators/:name | 撤销授权 |
| POST | /api/rooms/:id/settle | 结算 |
| GET | /api/matches | 历史记录 |
| GET | /api/players/:name/stats | 玩家统计 |
| WS | /ws/:roomId | WebSocket 连接 |

## 使用流程

### 开始比赛

1. 打开网站 → 点击"台球记分"
2. 选择玩家1、玩家2（可从预设选择或输入新名字）
3. 设置单价（默认5元）
4. 选择"你是谁" → 创建房间
5. 分享房间号给朋友（可选）

### 记录比分

1. 点击"记录本局"
2. 点击胜者头像
3. 选择赢球数（1-7 或自定义）
4. 确认

### 结算

1. 比赛结束后点击"结算"
2. 查看最终比分、球数差、转账金额
3. 确认结算，比赛记录保存到历史

### 查看统计

- 历史记录：查看所有已结算比赛
- 玩家战绩：点击玩家名查看详细统计和图表
